# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-10-13

### Added
- Initial release of npm-registry-mcp
- Package search with quality, popularity, and maintenance filters
- Package metadata retrieval (full package and specific versions)
- Lifecycle status checking
- Package publishing and unpublishing
- Version management (list versions, dist-tags)
- Token management (list, create, delete)
- Organization management (users, teams)
- Access control (team package access, package visibility)
- Security advisories
- Download statistics
- Custom registry support via NPM_REGISTRY_URL
